# Simple Calculator

A menu-driven calculator written in C.

## Supported operations
1. Addition
2. Subtraction
3. Multiplication
4. Division
0. Quit

## Number format
The calculator accepts integer operands.
Addition, subtraction and multiplication produce integer results.
Division uses floating-point arithmetic and prints decimal results
when necessary, without unnecessary trailing zeros.

## Input validation
Invalid menu choices are rejected.
Invalid numeric input can be entered again.
Division by zero prints: Error: division by zero
